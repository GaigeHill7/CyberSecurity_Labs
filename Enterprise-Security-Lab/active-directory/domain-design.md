# Active Directory Domain Design
## Purpose
This Document describes the Active Directory design for the JangoNet, including the domain structure, organizational unit hierarchy, administrative model, and security considerations.

## Domain Information
- Domain: jangonet.online
- Domain Controller: 'Jango_DC1'
- DNS Role: Active Directory-integrated DNS
- DHCP Role: Windows DHCP Server
- Domain Functional Role: Active Directory Domain Services
